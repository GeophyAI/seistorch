# seistorch has moved to sweepx

**seistorch is no longer maintained.** Its successor is
**[sweepx](https://github.com/DeepWave-KAUST/sweepx)** — wave-equation modeling, FWI, LSRTM and RTM
with PyTorch / JAX / CUDA backends.

```bash
pip install sweepx
```

- Code: <https://github.com/DeepWave-KAUST/sweepx>
- Docs: <https://sweepx.deepwave.group/>

The original seistorch code, used for Wang et al. (2023), IEEE TGRS,
[10.1109/TGRS.2023.3317529](https://doi.org/10.1109/TGRS.2023.3317529), is kept at tag
[`v-final`](https://github.com/GeophyAI/seistorch/tree/v-final) and on the `stable` and `dev` branches.
